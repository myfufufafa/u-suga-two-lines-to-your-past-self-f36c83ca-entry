A deterministic program that writes an original two-line warning to your past self to /output/entry.txt: one sentence about a specific moment — a grandmother's Sunday call skipped to finish a report — and one sentence saying why that moment mattered and what changed because of it.

## Run it

```sh
python3 main.py
```
